# বলের ল্যাব (Force Lab)

পঞ্চম শ্রেণির প্রাথমিক বিজ্ঞান, অধ্যায় ৭ "বলের ধারণা"-র জন্য ৬টি ইন্টারঅ্যাক্টিভ সিমুলেশন:

- দড়ি টানাটানি (বলের মাত্রা ও মোট বল)
- ঘর্ষণ (বিভিন্ন জায়গায় বল গড়ানো)
- লিভার (পাথর তোলা ও ভারসাম্য খেলা)
- হেলানো সমতল (ঢাল দিয়ে বাক্স তোলা)
- মাধ্যাকর্ষণ (জিনিস পড়ার তুলনা)
- কপিকল (কুয়া থেকে পানি তোলা)

## ব্যবহার

`index.html` ফাইলটি যেকোনো ব্রাউজারে খুললেই চলবে। ইন্টারনেট লাগে না।
GitHub Pages চালু থাকলে লিংক থেকেও সরাসরি খোলা যায়।
